# Twitter Analytics Dashboard

## Data Analytics Internship Project

This project was completed as part of my Data Analytics Internship. The project analyzes Twitter data using Microsoft Power BI and focuses on tweet engagement, media interactions, engagement rates, and high-performing tweets.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Visualization
- GitHub

## Project Objectives

The main objectives of this project are:

- Analyze Twitter engagement metrics
- Understand tweet interaction patterns
- Compare engagement rates
- Analyze media views and media engagements
- Identify monthly engagement trends
- Identify the top 10 tweets by engagement
- Create meaningful Power BI visualizations

## Tasks Completed

### Task 1 – Tweet Interaction Breakdown by Category

Analyzed URL clicks, user profile clicks, and hashtag clicks by tweet category using a clustered bar chart.

### Task 2 – Engagement Rate Comparison

Compared the engagement rate of tweets with app opens against tweets without app opens.

### Task 3 – Media Interaction by Day of Week

Created a dual-axis visualization comparing media views and media engagements by day of the week.

### Task 4 – Replies, Retweets and Likes Comparison

Created a bar chart comparing replies, retweets, and likes for tweets posted between June and August 2020.

### Task 5 – Monthly Engagement Rate Trend

Created a line chart comparing the monthly average engagement rate of tweets with media content and tweets without media content.

### Task 6 – Top 10 Tweets by Engagement

Identified the top 10 tweets based on the combined number of retweets and likes.
